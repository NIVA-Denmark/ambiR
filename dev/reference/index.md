# Package index

### AMBI functions

Core AMBI functions.

- [`AMBI()`](https://niva-denmark.github.io/ambiR/dev/reference/AMBI.md)
  : Calculates AMBI, the AZTI Marine Biotic Index
- [`MAMBI()`](https://niva-denmark.github.io/ambiR/dev/reference/MAMBI.md)
  : Calculates M-AMBI, the multivariate AZTI Marine Biotic Index

### Benthic quality indices

Other benthic quality index functions, including those derived from
AMBI.

- [`Hdash()`](https://niva-denmark.github.io/ambiR/dev/reference/Hdash.md)
  : Calculates H' the Shannon diversity index

- [`ES()`](https://niva-denmark.github.io/ambiR/dev/reference/ES.md) :
  Calculates ES the Hurlbert diversity index

- [`DKI()`](https://niva-denmark.github.io/ambiR/dev/reference/DKI.md) :

  Calculates DKI (*v1*), the Danish Quality Index

- [`DKI2()`](https://niva-denmark.github.io/ambiR/dev/reference/DKI2.md)
  : Calculates DKI (v2), the revised Danish Quality Index

- [`NSI()`](https://niva-denmark.github.io/ambiR/dev/reference/NSI.md) :
  Calculates NSI, the Norwegian Sensitivity Index

- [`ISI()`](https://niva-denmark.github.io/ambiR/dev/reference/ISI.md) :
  Calculates ISI, the Indicator Species Index

- [`NQI1()`](https://niva-denmark.github.io/ambiR/dev/reference/NQI1.md)
  : Calculates NQI1, the Norwegian Quality Index

### Utility functions

Help functions for quality indices.

- [`AMBI_species()`](https://niva-denmark.github.io/ambiR/dev/reference/AMBI_species.md)
  : Returns species list for AMBI calculations
- [`H_sal()`](https://niva-denmark.github.io/ambiR/dev/reference/H_sal.md)
  : Maximum H' as a linear function of salinity
- [`AMBI_sal()`](https://niva-denmark.github.io/ambiR/dev/reference/AMBI_sal.md)
  : Minimum AMBI as a linear function of salinity
- [`NO_species()`](https://niva-denmark.github.io/ambiR/dev/reference/NO_species.md)
  : Returns species list used by Norwegian index calculations
